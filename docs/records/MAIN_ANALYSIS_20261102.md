# 본 테스트 분석 (11/2, A vs B v2 — 〈작업실의 금세공인〉)

> 재현: `python analysis/analyze_main.py` (입력: `records/main_20261102_participants.csv`, `_tasks.csv` — 시트에서 `phase=main`만, 11/2 17:20 기록까지)
> 그래프: `records/main_20261102_chart.png`
> 지표 정의는 베타와 같음: 찾기 성공 = 첫 탭에 정답, 시간 = **맞힌 문제의 중앙값**(초), **완료한 참가자만** 집계.
> 표현은 "입증"이 아니라 **"뒷받침"** — 그룹당 6~9명. 아래 5번 한계를 함께 밝힌다.

## 0. 참여 흐름

| | 접속 | 사전 질문 답함 | 완료 | 완료율 |
| --- | --- | --- | --- | --- |
| A (글 설명) | 15 | 9 | **6** | 40% |
| B (확대·강조 v2) | 16 | 11 | **9** | 56% |

- 접속만 하고 첫 화면에서 나간 사람: A 6 · B 5. 문제 도중 그만둔 사람: A 3 · B 2
- 완료자 입력 방식: A 마우스 5·터치 1 / B 마우스 7·터치 2. 그림을 본 적 있음: A 0 / B 1
- 이전 테스트(베타·리허설) 참여 경험: A 4/6 · B 4/9

## 1. A vs B 전체

| | A | B v2 | 차이 |
| --- | --- | --- | --- |
| 전체 정답률 | 64% | **76%** | +12%p |
| 찾기 정답률 | 70% | **84%** | +14%p |
| 의미 문제 정답률 | 58% | **69%** | +11%p |
| 맞힌 문제 시간 중앙값 | 5.6초 | **3.0초** | −2.6초 |
| 찾기 시간 중앙값 (맞힌 것) | 5.1초 | **2.5초** | 약 절반 |
| 찾기 오답 탭 (1인 평균) | 5.2회 | **1.4회** | |
| 시간 초과 / 모르겠어요 | 1 / 11 | 0 / 9 | |
| 설문 q1 "어느 부분 이야기인지 바로 알 수 있었다" (1~5) | 3.3 | **4.6** | +1.3 |
| 설문 q2 "어려웠던 것 없었다" | 0명 | **4명** | |

→ 정확도·시간·헤맨 정도·주관 평가 모두 B가 앞섬. 베타(정답률 63% → 79%)와 같은 방향.

## 2. 차이가 큰 곳 / 작은 곳

| 과업 | A 정답률 | B 정답률 | 메모 |
| --- | --- | --- | --- |
| T2 수정 용기 찾기 | 33% (14.8초) | **89%** (6.6초) | 가장 큰 차이 |
| T2 수정 용기 의미 | 17% | **67%** | |
| T3 매 찾기 | 17% (10.7초) | **67%** (2.8초) | 작은 대상. A는 6명 중 1명만 끝내 찾음 |
| T1·T4·T7 찾기 | 100% | 89% | 큰·눈에 띄는 대상은 A도 쉽게 찾음 (B는 각 1명 오답) |
| **T5 앉은 사람의 정체 (의미)** | 67% | **33%** | ⚠️ B가 낮음 — 3번 |
| T6 진열품 (의미) | 50% | 56% | 차이 작음 |

유형별: 위치 디테일의 의미 A 58% → B 81% (+23%p), **일반 이해(T5·T6) A 58% → B 44% (−14%p)**.

## 3. B v2의 약점

- **T5 "앉은 사람의 정체"**: B 9명 중 4명이 1번 보기를 고름(정답 2번). 확대·강조는 "어디"를 찾는 데는 강하지만, 위치가 없는 해설(정체·해석)은 기억을 돕지 못함. 설문에서도 B의 어려운 이유 1위가 "해설 내용이 기억나지 않아서"(3명)
- 쉬운 찾기(T1·T4·T7)에서 B 각 1명 실패: T1은 PHG9V 오답, T4·T7은 PGU7N "모르겠어요". PGU7N은 해설을 13.7초만 보고 정답률 18%로 B 최저 — 해설을 거의 건너뛴 경우로 보임 (제외하지 않고 그대로 집계)

## 4. 참가자 목소리 (q3 기타, 원문)

- PTBXC(A): "그림과 설명이 세로로 쭉 나열되다보니 설명을 보고 다시 올려서 그림을 보고, 또 내려와서 설명을 읽고 다시 올려 그림을 보고의 반복" — 문제 정의(글과 그림을 번갈아 봐야 함)를 그대로 말해 줌
- PZYTQ(A): "매가안보였음"

## 5. 한계

- 그룹당 6~9명, 그룹 크기가 다름 (A 6 · B 9). 통계 검정 없이 경향으로만 말한다
- 재참여자가 절반 가까이 (A 4/6, B 4/9). **첫 참여자만**: 찾기 A 60% vs B 92%, 의미 A 33% vs B 70% — 방향은 같지만 A 첫 참여자는 2명뿐
- 해설을 본 시간 중앙값 A 32.7초 vs B 45.6초 — B가 해설을 더 오래 봄 (B 화면이 장면을 넘기는 방식이라 시간이 더 듦)
- 대부분 마우스(PC) 참가 — 실제 사용 상황(미술관에서 휴대폰)과 다름
